# Redesigned home dashboard - standalone experimental branch

This branch independently adds the card-style home dashboard, Home button,
installed-app shortcuts, and dashboard color theme to stock upstream v1.1.1.
It does not include Spotify orientation, DPI, Ford margins, or Waze startup.

This is an opinionated UI redesign, suitable for review but not a small PR.
Tested only as part of the complete integrated local build; standalone branch
has not been independently compiled or used in a car.
