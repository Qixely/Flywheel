# Ford SYNC 4 first-connection width heuristic

Suppresses an anomalous ~586px horizontal margin on 1920x1080/240DPI
head-unit configuration during first connection. This is an empirical
heuristic from one Ford SYNC 4 setup and may be unsafe for other head units.
No independent build or head-unit regression tests performed on this branch.
Do not merge upstream without protocol-level validation.
