# Per-application projected DPI - standalone feature

Based on upstream Flywheel v1.1.1, without the Ford PR or local dashboard.
Stores per-package 20-DPI stepped values (default 240, standard max 480,
advanced max 640), applies each when its virtual display starts and on
subsequent task selection. Settings includes installed-app picker and reset.

Vehicle-tested only as part of the integrated local build. This standalone
branch has not been compiled here; review and compile independently before PR.
