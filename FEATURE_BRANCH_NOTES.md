# Optional custom Spotify media player - standalone experimental branch

Contains the original Flywheel media-session panel, a Spotify-specific overlay
with enlarged controls and artwork, and a Settings choice between native
Spotify (the default) or the custom panel. Does not include the Ford protocol
fix, dashboard, DPI, Waze startup, or Android orientation override.

The custom player was vehicle-tested only in the combined integrated build.
Provider-specific UX likely needs a generic media player design before it
would be suitable for upstream. Not independently built or tested here.
